# Welcome to jom-QA 🚀

jom-QA is an open-source, autonomous AI-powered QA automation engine designed to simplify software testing. By blending the orchestrational power of **Python**, the blistering performance of **Rust**, and a web-based **Laravel (Filament)** SaaS dashboard, jom-QA automatically parses SRS documentation and executes live telemetry tests on cross-platform applications.

## 🛠️ The Core Ecosystem

- [jom-qa](https://github.com/jom-qa/jom-qa) - The main parsing engine, OpenRouter gateway, and autonomous execution runtime.
- [jom-qa-panel](https://github.com/jom-qa/jom-qa-panel) - The web dashboard, tenant manager, and third-party credential store.
